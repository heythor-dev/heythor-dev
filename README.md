## 🌟 Projeto em Destaque

### **Lumind**
Desenvolvido em parceria com colegas de faculdade, o Lumind é um sistema voltado para psicólogos e pacientes com Transtorno do Espectro Autista (TEA). O intuito do projeto é manter um contato próximo entre o profissional e o paciente fora das consultas, além de auxiliar diretamente na rotina e organização da pessoa com TEA.
